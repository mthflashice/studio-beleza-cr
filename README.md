# 💇‍♀️ Studio de Beleza CRL

> Sistema interativo de agendamento e vitrine de serviços para salão de beleza.

Este projeto foi desenvolvido para proporcionar uma experiência de agendamento fluida para os clientes do Studio de Beleza CRL, permitindo a visualização de serviços e contato direto.

## 🚀 Tecnologias Utilizadas

*   **Frontend:** HTML5, CSS3, JavaScript (ES6+)
*   **Deployment:** [Netlify](https://www.netlify.com)
*   **Versionamento:** Git & GitHub
